# Основные топики turtlesim

## 1. `/turtle1/cmd_vel`
- **Тип сообщения:** `geometry_msgs/msg/Twist`
- **Назначение:** Отправка команд управления движением (заданием скорости) черепахи.

### Поля сообщения Twist:
- **`linear`** (линейная скорость, м/с):
  - `x`: движение вперёд / назад.
  - `y`: движение влево / вправо (стрейф).
  - `z`: движение вверх / вниз.
- **`angular`** (угловая скорость, рад/с):
  - `x`: крен (roll).
  - `y`: тангаж (pitch).
  - `z`: рыскание (yaw) — поворот вокруг своей оси (влево / вправо).

---

## 2. `/turtle1/pose`
- **Тип сообщения:** `turtlesim/msg/Pose`
- **Назначение:** Публикация текущего состояния (положения и скорости) черепахи в реальном времени.

### Поля сообщения Pose:
- `x`: текущая координата по оси X (в пределах окна от 0 до 11).
- `y`: текущая координата по оси Y (в пределах окна от 0 до 11).
- `theta`: текущий угол поворота черепахи в радианах.
- `linear_velocity`: текущая линейная скорость.
- `angular_velocity`: текущая угловая скорость.
